# Neon Reactor

A self-contained procedural showcase built to feel like a live shader toy inside `vglib`.

## What It Does

- renders an infinite neon reactor corridor with a raymarched fragment shader
- exposes palette, rhythm, bloom, vignette, and camera energy controls in ImGui
- avoids external model and texture dependencies so it is easy to build and run

## Controls

- `Animate` pauses or resumes the scene
- `Speed`, `Swirl`, and `Density` reshape the corridor motion
- `Glow`, `Bloom`, and `Contrast` control the final look
- `Energy` and `Pulse` push the reactor harder when you want it louder

## Why This One

Most of the examples in this repo are feature demos. This one is more of a signature piece: compact, stylized, and instantly readable as a showcase even before you touch a control.
