# Orbital Cathedral

A denser showcase built around instanced geometry instead of a fullscreen-only effect.

## What It Does

- draws thousands of animated cube instances as a twisting architectural sculpture
- uses the shared camera, floor, and atmosphere helpers so it sits naturally inside `vglib`
- exposes controls for twist, span, pulse, glow, and palette direction

## Why It Exists

The goal here is different from `neon_reactor`: less shader toy, more "this renderer can stage a scene."
